# Financial Management (FM) Learning Portal & Interactive Excel Labs

A comprehensive Financial Management learning portal connecting core corporate finance theory (Time Value of Money, Capital Budgeting, Cost of Capital) with hands-on interactive MS Excel simulation and practical finance laboratories.

## 🚀 Features

- **Interactive Financial Labs**:
  - Time Value of Money (TVM) Laboratory
  - Capital Budgeting Excel Lab & Universal Suite
  - Net Present Value (NPV) Lab
  - Internal Rate of Return (IRR) Lab
  - Modified Internal Rate of Return (MIRR) Lab
  - Accounting Rate of Return (ARR) Lab
  - Cost of Capital, Cost of Equity, Cost of Debt, and Cost of Preference Shares Labs
- **Universal Learning Hub**: Theory, formulas, calculations, and practical Excel modeling guides.
- **Dynamic Portal Architecture**: Fast, lightweight vanilla HTML5, CSS3, and JavaScript interface.

## 🛠️ Getting Started

Simply open `index.html` in any modern web browser or serve it with any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Then navigate to `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages

To make this live online for students and learners:
1. Go to repository **Settings** > **Pages**.
2. Select `Deploy from a branch` and choose the `main` branch with folder `/ (root)`.
3. Save and your FM Portal will be live at `https://<username>.github.io/<repo-name>/`.
