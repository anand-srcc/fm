📐 Essential Corporate Finance Formulas

Quick lookup reference for examinations and financial modeling.

⏱️ Time Value of Money Formulas

  • • Single Sum FV: FV = PV × (1 + r)^n
  • • Single Sum PV: PV = FV / (1 + r)^n
  • • Ordinary Annuity PV: PVA = PMT × [(1 - (1+r)^-n) / r]
  • • Growing Perpetuity PV: PV = C1 / (r - g)
  • • Effective Annual Rate: EAR = (1 + r_nom/m)^m - 1

🏢 Capital Budgeting Formulas

  • • Net Present Value (NPV): NPV = Σ [CF_t / (1+k)^t] - CF_0
  • • Internal Rate of Return (IRR): Discount rate where NPV = 0
  • • Profitability Index (PI): PI = PV of Inflows / Initial Outlay
  • • Accounting Rate of Return: ARR = Avg PAT / Avg Investment
  • • Equivalent Annual Annuity: EAA = NPV / PVIFA_{k, n}

⚖️ Cost of Capital Formulas

  • • WACC: WACC = w_d·K_d(1-T) + w_p·K_p + w_e·K_e
  • • Cost of Debt (Redeemable): Kd ≈ [I(1-T) + (RV-NP)/n] / [(RV+NP)/2]
  • • Cost of Equity (Gordon): Ke = D1/P0 + g
  • • Cost of Equity (CAPM): Ke = Rf + β × (Rm - Rf)
  • • Cost of Preference: Kp = [Dp + (RV-NP)/n] / [(RV+NP)/2]
